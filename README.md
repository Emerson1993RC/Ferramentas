## 📋 Sobre

Este repositório reúne ferramentas práticas e automatizadas desenvolvidas para otimizar a rotina do enfermeiro na **Atenção Primária à Saúde (APS)**. Todas as ferramentas são utilizadas no dia a dia da unidade básica de saúde e visam agilizar processos, organizar dados e melhorar o cuidado à população.

---

## 🚀 Ferramentas Disponíveis

| Ferramenta | Descrição | Arquivo |
|---|---|---|
| 🖥️ **PEC** | Acesso ao Prontuário Eletrônico do Cidadão | Link externo |
| 📋 **Uso Diário** | Textos pré-prontos para copiar: HAS, DM, visitas e rotinas | `Uso diario.html` |
| 🏥 **Atendimento Demanda Livre** | Frases e códigos prontos para atendimentos espontâneos | `AtendimentoDL.html` |
| 📤 **UPLOAD** | Sistema de upload de arquivos e documentos | Link externo |
| 🤰 **Pré-Natal** | Textos, códigos SIGTAP e orientações para pré-natal | `Pre_Natal.html` |
| 🍼 **Visita Puerperal** | Frases prontas para visita domiciliar puerperal | `Visita Puerperal.html` |
| 👶 **Puericultura** | Textos para acompanhamento do desenvolvimento infantil | `Puericultura.html` |
| 🔬 **Mamografia e Citopatológico** | Códigos e textos para registro de resultados de rastreamento | `para-mamografia-citopatoligico.html` |
